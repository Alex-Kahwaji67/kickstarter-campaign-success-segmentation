# Data Notes

Raw data should not be committed to the public GitHub repo unless the dataset source and license are confirmed.

For local reproduction, place the following file in this folder:

```text
Kickstarter_data.csv
```

`Kickstarter_data.csv` is the main training/evaluation file used for the public-facing analysis. The staged public notebook and script use only this file.

Before publishing this repo, confirm the dataset source and license. If the source cannot be confirmed, keep the data out of GitHub and describe only the schema, cleaning steps, and results.
